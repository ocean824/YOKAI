# YOKAI — Game Design Bible

## Pillars
1. Precision action-RPG combat with readable commitment, mastery and boss depth.
2. Creature discovery, bonding, evolution and fusion are central—not side collecting.
3. Divine Canvas changes combat/world state through authored systemic interactions.
4. Mythic Japanese-inspired world with a distinct painterly identity; research respectfully and create original lore/creatures alongside folklore inspiration.
5. Solo-first complete adventure with co-op/PvP designed as compatible layers, not compromises to PvE.

## Core loop
Explore region → investigate supernatural disturbance → traverse/puzzle/Canvas interaction → encounter/tame/bond with Yokai → fight humans/Yokai/bosses → harvest knowledge/materials → evolve/fuse/build team → restore/corrupt/reshape regional state → unlock deeper mythic layer.

## Player combat
Third-person lock-on action combat: light/heavy, dodge, guard/parry, stance/weapon skills, Yokai assist/swap, elemental/status interactions, Canvas techniques and ultimate/synchronization. Animation commitment, stamina/posture/resource values and cancel windows are data-driven and Gauntlet-tested.

## Creature system
Species identity, temperament, rarity/encounter ecology, stats/attributes, move pool, passive traits, affinity, bond, evolution branches, fusion compatibility, inherited traits/moves and visual lineage. Avoid reducing creatures to interchangeable stat blocks.

## Divine Canvas
Canvas actions are verbs with world/combat contracts: reveal, bind, sever, bridge, cleanse/corrupt, redirect element, create temporary terrain, expose weakness and manipulate encounter geometry. Every verb must have authored limitations/cost/counterplay.

## Progression
Player mastery + equipment + Yokai roster/bond/evolution + Canvas mastery + regional knowledge. No progression system should make action skill irrelevant.

## World
Interconnected regions with settlements, wilderness, shrines/ruins, Yokai ecologies, dungeons and mythic overlays. Regional state reacts to major choices/boss outcomes.

## Bosses
Multi-phase signature encounters combining combat, creature interactions and Canvas mechanics. Boss AI Toolkit/Boss Animations/BlackMoon/Sci-Fi Myth assets are implementation/reference accelerators, not canon.

## Multiplayer
Co-op supports exploration/bosses with deterministic authority rules and explicit summon/creature ownership. PvP is separately balanced; no PvP balance change silently damages PvE identity.

## V1→V3
V1 proves one complete region, deep combat, 20+ representative Yokai, evolution/fusion, Canvas vertical slice, bosses and co-op prototype. V2 expands regions/roster/build diversity/endgame/multiplayer. V3 is complete world, mature competitive/co-op systems, live content hooks where desired and AXIOM-native parity/improvement.
